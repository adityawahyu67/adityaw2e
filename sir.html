EKSPERIMEN 10 + 20

Jangan jalankan terlebih dahulu. Prediksikan hasil:

let a = "10"; let b = "20"; console.log(a + b);
Pertanyaan Jawaban Kamu
Apa output program? 1020
Mengapa hasil tersebut terjadi? Karena a dan b bertipe String (ditandai tanda petik), sehingga operator + menggabungkan teks (konkatenasi), bukan menjumlahkan angka.
Apakah a dan b bertipe Number? Tidak, keduanya bertipe String.

Uji sekarang. Apakah prediksimu benar? Jelaskan: Ya, benar. Hasilnya 1020 karena kedua variabel diapit tanda petik sehingga dibaca sebagai teks.

G. TANTANGAN PROGRAM HITUNG NILAI

Buat program dengan input nilai tugas, UTS, dan UAS. Konversikan semua input menggunakan Number(), lalu hitung rata-rata dengan rumus (tugas + UTS + UAS) / 3.

let tugas = Number(prompt("Nilai Tugas:")); let uts = Number(prompt("Nilai UTS:")); let uas = Number(prompt("Nilai UAS:")); let rataRata = (tugas + uts + uas) / 3; console.log("Rata-rata = " + rataRata);

Algoritma saya:

  1. Meminta input nilai tugas, UTS, dan UAS via prompt().
  2. Mengubah semua nilai input dari String menjadi Number menggunakan Number().
  3. Menhitung rata-rata dengan rumus (tugas + UTS + UAS) / 3.
  4. Menampilkan hasil rata-rata ke konsol.

H. THINK PAIR SHARE

Pertanyaan Jawaban
Mengapa prompt() perlu dikonversi jika hasilnya ingin dihitung? Karena prompt() selalu mengembalikan tipe String. Jika tidak dikonversi ke Number, penjumlahan akan menggabungkan teks alih-alih menghitung angka.
Apa perbedaan "10" dengan 10? "10" adalah String (teks), sedangkan 10 adalah Number (angka murni).
Apa yang terjadi jika lupa Number()? Terjadi kesalahan logika data, contohnya "10" + "20" menghasilkan "1020".

Pair: Bandingkan jawaban dengan teman. Apakah sama? Mengapa bisa berbeda? Sama, karena konsep tipe data pada JavaScript berlaku secara umum.

Share: Sampaikan satu temuan penting kepada kelas: Penggunaan Number() sangat penting saat memproses input berupa angka dari prompt().
